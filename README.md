# Neon Rush — Web Racing Game

A mobile-first arcade racing game built with plain HTML, CSS and Canvas JavaScript.

## Features
- Fullscreen responsive canvas
- Touch steering + keyboard A/D + arrow keys
- Detailed neon sports car
- Night city / neon road environment
- Scrolling lane markings and roadside lights
- Enemy traffic
- Coins and score system
- Lives and crash effects
- High score saved with localStorage
- Pause / resume / restart
- Car selection: Cyan, Red, Gold
- Synthesized visual/audio-ready structure without external assets
- No frameworks or external libraries required

## Run locally
Open `index.html` in a browser.

For Termux, from this folder you can run:
python -m http.server 8080

Then open:
http://localhost:8080

## Deploy with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `game.js`.
3. In repository Settings → Pages, select the main branch/root folder.
4. Save and wait for GitHub Pages to publish.

No build step is required.
